# Second-device verification checklist

Independent HTTP clients have passed registration, login, upload, search and download; login and download also passed after a server restart. Two physical devices have not yet been tested. On device A register a student, upload a non-sensitive PDF, and note its title. On an independent device B open the same HTTPS site, log in with that account, find the title, download the PDF, and compare its contents. Verify guest upload and download are rejected and the student cannot access admin routes. Restart the backend in Render and repeat the login and download. Check the corresponding user and material rows and private bucket object in Supabase. Do not claim two physical devices were used if only independent browser sessions were available.
