## Design changes
- **Direction:** a university library card. Cool paper background, ink text, cobalt for actions, a highlighter-yellow tab for the current page, serif headings with a plain system sans for UI (no web fonts, works offline). Each material card has a coloured left spine by category; the same colour is used for the category chips on the home page.
- **Home:** the first screen is the task — a search box and category chips; the backend connection panel moved to the bottom as small status text.
- **Navigation:** underlined tab bar, current page marked with `aria-current` and colour; skip link; visible 3 px focus ring with a yellow halo.
- **Languages:** English, Russian and **Kazakh** (new). The materials page (labels, counts, dates, errors) is now translated too — previously it was English only.
- **Forms:** show-password checkbox, 44 px controls, plain error text; 429 "too many attempts" message; sign-in asks for the authentication code only when the account has 2FA; new Security page.
- **Mobile:** single column at ≤ 720 px, no horizontal scroll at 390 px.
